# 🎮 Frontend Games

A collection of interactive browser games built using **HTML, CSS, and JavaScript**.

This repository contains simple, fun and visually engaging frontend games created to improve my web development, JavaScript logic and UI design skills.

---

## 🚀 Games

### ⚡ Neon TypeX
A neon-style typing game designed to improve typing speed and accuracy.

**Features:**
- ⌨️ Typing speed challenge
- 🎯 Accuracy tracking
- ⚡ Neon UI
- 📊 Score system

---

### 🔢 Number Guess Game
A simple number guessing game where the player tries to find the randomly generated number.

**Features:**
- 🎲 Random number generation
- 💡 Higher / Lower hints
- 🏆 Attempt tracking
- 🔄 Restart option

---

### 🐍 Slither_X
A modern snake-style browser game with a custom visual design.

**Features:**
- 🐍 Snake movement
- 🍎 Food collection
- 🏆 Score system
- 💀 Game-over detection
- 🎨 Custom UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Responsive Web Design
